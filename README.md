# DEHTIAROVA Photography

Custom bilingual portfolio homepage for a Budapest photographer.

## Included

- Responsive editorial design
- Ukrainian and English interface
- Portfolio lightbox
- Mobile navigation
- Session enquiry form that opens a pre-filled WhatsApp message
- Instagram, Telegram and WhatsApp links
- Accessible structure and reduced-motion support
- SEO title and description
- Custom favicon

## Preview locally

Open `index.html` in a browser. For the most accurate preview, serve the directory with any static web server.

## Temporary content

The current photographs are temporary Unsplash images. Replace them with the photographer's original files before public launch. The About portrait and testimonial are also explicitly marked as temporary.

## Next phase
